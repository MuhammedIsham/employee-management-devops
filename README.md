# Employee Management System with DevOps CI/CD

## Project Overview

A full-stack Employee Management System built using Flask and PostgreSQL, containerized with Docker, automated using Jenkins CI/CD, monitored using Prometheus and Grafana, and deployed on an AWS EC2 instance.

---

## Features

- Employee Management CRUD
- Flask Web Application
- PostgreSQL Database
- Dockerized Application
- Docker Compose Deployment
- Jenkins CI/CD Pipeline
- Automatic Deployment
- Nginx Reverse Proxy
- Prometheus Monitoring
- Grafana Dashboard
- AWS EC2 Deployment

##  CI/CD Pipeline

1. Developer pushes code to GitHub
2. Jenkins detects changes
3. Docker images are built
4. Containers are deployed automatically
5. Application becomes available on AWS EC2
